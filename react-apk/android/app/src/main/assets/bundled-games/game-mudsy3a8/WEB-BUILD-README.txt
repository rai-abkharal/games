ARROW FLOW — WEB BUILD

Complete 100-level game, with full-viewport mobile portrait layout and saved progress.

WEB HOSTING
Upload index.html, assets/ and audio/ together to your static web host.
Keep the folder structure unchanged. No backend or build step is required.

OFFLINE PLAY
Open Play.html directly in a modern browser. All game data and sounds are embedded.

PROGRESS
Current level, cleared arrows, hearts and hint usage save automatically in this browser on this site. Returning to the same site resumes the saved board. Clearing browser site data removes this save.

MOBILE
Portrait gameplay fills the available browser width and height, without side borders. Arrows retain their proportions as the browser size changes.

LATEST VISUAL FIXES
Arrowheads have a visible straight neck before the final bend; the Level 3 bent arrow has been reshaped for clearer separation.
Victory and Congrats overlays now fade smoothly to transparent before being removed, revealing the next level underneath.
