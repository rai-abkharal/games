# Sky Pop

Portrait 2D hyper-casual tap game.

Tap to flap the bird through the moving sky gates. Every gate passed increases the score. The gap tightens and speed increases over time.

The standalone `index.html` is browser-playable without executing TypeScript. The `src/main.ts` entry is included for the platform's official Vite + Phaser build pipeline.

Platform registration is included in `build-registration.js`.
