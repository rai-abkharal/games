Extract the ZIP and double-click index.html. No installation, local server or internet connection is required.

GAME
Farmer Pedro

HOW TO PLAY
1. Extract the whole farmer-pedro-offline folder. Do not move index.html by itself.
2. Double-click index.html.
3. Use Chrome, Edge, or Firefox with WebGL enabled.
4. Click Play. Use W/A/S/D or the arrow keys to drive and steer the harvester. Touch controls remain available on mobile browsers.

OFFLINE DESIGN
- index.html is the offline entry point.
- All 117 runtime resources are embedded in embedded-resources.js, while inspectable copies remain under game/ and assets/.
- The original fetch/XMLHttpRequest loading path is intercepted only for packaged resources.
- Babylon's required Draco decoder is local. The package never downloads it from Babylon's CDN.
- The local GameSnacks adapter keeps progress in browser storage and disables ads, analytics, cloud saves, accounts, leaderboards, and tracking.
- Rewarded ads are unavailable offline and never grant a reward.

SAVING
The adapter uses localStorage when the browser permits it for file:// pages. If a browser denies file-page storage, play still starts but saving falls back to memory and lasts only until the tab closes. Do not use private/incognito mode if you want persistent progress.

IMPORTANT LIMITATION
The build requires WebGL. Static integrity, embedded-resource, JavaScript, JSON, model, audio, image, font, and WebAssembly checks passed during packaging. The available test browser blocked file:// navigation and its live GameSnacks session reported “WebGL not supported,” so a visual end-to-end gameplay run could not be honestly completed in that environment. A normal desktop browser with WebGL enabled is required.

ABOUT THE CODE
This is the deployed, minified browser build, not the developer's original editable source project. See CODE-STRUCTURE.md for architecture and modification notes. source-reference/ preserves the fetched page and game entry HTML plus the unmodified deployed game bundle.
